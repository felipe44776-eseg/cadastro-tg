# Cadastro de tema de TG

Formulário para colegas cadastrarem o tema do Trabalho de Graduação. Projeto de aluno na disciplina de Metodologia Científica da Faculdade ESEG (docente Lina Cardona), organizado por Felipe Marins. Não é um sistema oficial da ESEG.

Este repositório tem só a página. Os cadastros não ficam aqui: o envio vai para uma planilha privada do organizador.
